# 라인 유닛 3D 케이스 요구사항 명세

> 대상: 기구 설계자(3D 모델링/출력). 이 문서는 **요구사항·제약**을 정의하며, CAD/STL은 별도 산출물.
> 라인 유닛 = **라즈베리파이 + Zebra 프린터(USB)**([`../SOLUTION.md`](../SOLUTION.md) §1). 케이스는 **Pi를 담고 프린터에 부착/근접 고정**한다.
> ⚠️ **정확 치수는 확정 Pi 모델 + 실측 후 확정.** 아래 값은 설계 착수용 기준이며 `[실측]` 표기는 실물 측정 필요.

---

## 1. 목적 / 범위
- Pi 보드와 배선을 **먼지·충격·오조작**으로부터 보호하고, 프린터 옆/위에 **안정적으로 고정**.
- 현장 작업자가 **무도구로 접근**해야 하는 것: 전원 재투입, 상태 확인. **가끔 접근**: SD 카드 교체, 케이블 재연결.
- 케이스는 **프린터를 덮지 않는다**(라벨 배출구·용지 커버·전원 버튼 간섭 금지).

## 2. 대상 하드웨어

### 2-1. 라즈베리파이 (4 또는 5, 64-bit)
- 보드 치수 ~**85.6 × 56.5 × ~17mm**(커넥터 포함 높이 상이) `[모델 확정 시 고정]`.
- 장착 홀: 표준 **58 × 49mm, Ø2.7mm 4점**(M2.5).
- 발열: Pi4/5는 부하 시 발열 큼 → **히트싱크 또는 팬 필수 고려**(§4).
- 포트(레이아웃은 Pi4 기준, Pi5는 상이 `[확정 필요]`):
  - USB-A ×4 (프린터 USB-B 케이블 1개 사용)
  - RJ45 LAN ×1 (유선 권장)
  - 전원: Pi4=USB-C / Pi5=USB-C(PD)
  - microSD: 보드 하단(반대편) — **교체 접근구 필요**
  - GPIO 40핀: 미사용(팬 전원으로 활용 가능)

### 2-2. Zebra 프린터 (검증: ZD421 203dpi)
- 연결: 프린터 **USB-B** → Pi **USB-A** 케이블.
- 프린터 footprint/높이 `[실측]` — 케이스가 프린터에 부착형이면 상단/측면 마운트 기준면 정의 필요.
- **간섭 금지 영역**: 라벨 배출구(전면), 용지 롤 커버(상단 개폐), 전원/피드 버튼, 방열구.

## 3. 배선 / 커넥터 요구
- 케이블 인출구 3개: **① Pi 전원(USB-C)**, **② LAN(RJ45)**, **③ 프린터 USB(A→B)**.
- 인출구는 **케이블 굴곡 반경 확보**(급격한 꺾임 금지) + 스트레인 릴리프(장력 완화) 홈.
- 프린터-Pi USB 케이블은 **짧게**(20~30cm) 정리되도록 내부 클립/가이드.
- (선택) 전원 분기: 프린터·Pi를 한 어댑터/멀티탭으로 → 인출 최소화.

## 4. 열 관리 (필수 검토)
- Pi4/5 상시 구동(24/7) → **수동 히트싱크 + 통풍구** 최소, 고온 공장은 **5V 팬** 권장.
- 통풍구: 흡기(하단/측면) + 배기(상단) **자연대류 경로**. 먼지 유입 최소화 위해 **경사 슬릿/방진 메시** 고려.
- 팬 장착 시: 40mm 5V 팬 마운트(Ø32mm 홀 + 4점) + GPIO 5V/GND 배선 홈.
- CPU 스로틀링 방지 목표(케이스 내부 ≤ 주변+15℃ `[검증 필요]`).

## 5. 접근성 / 유지보수
- **SD 카드**: 무분해 교체 가능한 슬롯 개구부(Pi 하단 위치).
- **포트**: LAN/USB/전원 커넥터 **외부 노출 또는 개구부**.
- **상태 표시**: Pi 전원 LED 또는 (선택) 케이스 외부 상태 LED 창.
- **재부팅**: 전원 케이블 재투입으로 충분(systemd 자동 상주). 별도 버튼 불요, 있으면 편의.
- 조립: **스냅핏 또는 M2.5 나사 4점**. 현장에서 상판만 열어 SD/케이블 접근.

## 6. 장착 / 고정
- 옵션 A **프린터 상단 부착**: 프린터 상판 커버 개폐 간섭 없는 위치(후면/측면). 양면 VHB 또는 브래킷.
- 옵션 B **독립 스탠드**: 프린터 옆 배치, 미끄럼 방지 패드/나사 고정.
- 진동/이동 대비 Pi 보드 4점 고정 필수(커넥터 헐거움 방지).

## 7. 재료 / 환경
- 재료: **PETG 또는 ABS**(공장 온도·내구). PLA는 고온 환경 변형 위험 → 지양.
- 색상: 무광 다크(오염 눈에 덜 띔) 또는 브랜드 색.
- 환경: 먼지·진동·상시 통전. IP 등급 요구는 현장별 `[확인]`(일반 공장 실내 = 비방수 허용).

## 8. 산출물 / 검수 체크리스트
설계 완료 시 확인:
- [ ] 확정 Pi 모델 실측 반영(보드·포트·SD 위치)
- [ ] 3개 케이블 인출구 + 스트레인 릴리프
- [ ] 통풍(+팬 옵션) 경로, 내부 온도 검증
- [ ] SD/포트 무분해 접근
- [ ] 프린터 간섭 영역(배출구·커버·버튼·방열구) 회피 확인
- [ ] Pi 4점 고정 + 케이스 조립(스냅핏/나사)
- [ ] 프린터 부착/스탠드 고정 방식 확정
- [ ] 시제품 1개 출력 → 실 Pi+ZD421로 조립·발열·인쇄 검증

> 소프트웨어/설치는 이미 검증됨([`../PILOT.md`](../PILOT.md) §8-1 드라이런). 케이스는 **파일럿 병렬 진행 가능**하며, 실 Pi 입고(~3주) 시 시제품 조립 검증.
